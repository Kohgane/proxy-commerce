# 타오바오 — 폰에서 담고, PC에서 마무리

## 실측이 닫은 문 (2026-09-11, 상하이 · 오너 아이폰)

| 무엇을 | 어디서 | 결과 |
|---|---|---|
| `e.tb.cn` 단축 링크 | **중국 IP** | 리다이렉트만으로 최종 URL에 `id`·`price`·`tk` 실림 — **로그인 불요** |
| `e.tb.cn` 단축 링크 | VPN **전체(Global)** · 해외 IP | **연결 거부** |
| `m.intl.taobao.com` 상세 | VPN 온(+82) / 오프(+852) | **IP 무관 로그인 벽** |

→ **서버측 타오바오 경로는 0입니다.** 코드도 플래그도 두지 않았습니다.
실측이 닫은 문 앞의 "혹시" 코드는 보험이 아니라 **부채**입니다 —
끈 채로 남기면 다음 사람이 켜 보고 같은 실패를 다시 겪습니다.

**폐기:** 서버 해석기 · 폰 fetch · 게스트 mtop h5.

## 동작하는 흐름

```
폰(중국망): 타오바오 앱 → 공유 → 단축어「URL 확장」
                ↓
        제목 · 상품번호 · 가격(CNY) · 링크 저장
                ↓
PC(로그인된 타오바오 탭): 고가수집기 → 이미지 · 옵션 보강 → 등록 가능
```

**펴는 일은 폰이 합니다**(중국망에 있으니까).
**나머지는 확장이 합니다**(로그인 세션이 그 브라우저에만 있으니까).

## 두 갈래 — 화면이 어느 쪽인지 말합니다

| 폰이 폈나 | 담기는 것 | 아직 없는 것 | 마켓 등록 |
|---|---|---|---|
| ✅ VPN 끔 **또는 규칙/Smart 모드** | 제목 · 상품번호 · **가격** · 링크 | 이미지 · 옵션 · 상세 | **가능** |
| ❌ VPN **전체(Global) 모드** | 제목 · 링크 | 가격 · 이미지 · 옵션 · 상세 | 닫힘 |

**VPN이 켜졌느냐가 아니라 중국 사이트를 터널로 보내느냐가 가릅니다.**
「중국 사이트 우회(规则/Smart) 모드」면 VPN이 켜져 있어도 그대로 작동합니다 —
아스트릴은 Smart Mode, Shadowrocket/Clash류는 기본 규칙 모드입니다.

전체 모드일 때 화면이 그대로 말합니다 —
「VPN이 전체(Global) 모드면 링크 해석이 막혀요 — 규칙/Smart 모드로 바꾸고 다시 공유하시면
가격·상품번호까지 담깁니다」.

**가격은 공유한 그 순간의 값입니다** — 실시간 시세가 아닙니다. 화면에 그렇게 표시됩니다.

## 등록 게이트

가격이 없으면 **서버가** 마켓 등록을 막습니다(버튼만 숨기는 게 아닙니다).
게이트는 **가격이 실제로 도착했을 때만** 열립니다 — 이미지·옵션만 채워져도 닫힌 채입니다.
마진을 낼 수 없는데 0으로 채우면 그건 계산이 아니라 날조입니다.

## 단축어 만들기 (v2)

**단축어 앱 → 새 단축어 → 공유 시트에서 받기 켜기**(입력: URL **및 텍스트**)

| 순서 | 동작 | 설정 |
|---|---|---|
| ① | **URL 확장**(Expand URL) | 입력 = 공유된 항목 |
| ② | URL 콘텐츠 가져오기 | `https://<도메인>/api/v1/collect/one` · POST · `Authorization: Bearer <토큰>` |
| | | JSON: `url` = 공유된 내용 그대로 · `final_url` = ①의 결과 |
| ③ | 결과 보여주기 | `message` |

> **VPN이 켜져 있어도 규칙/Smart 모드면 그대로 됩니다.** 전체(Global) 모드만 막힙니다.
> 켜져 있으면 ①이 실패하는데, 그래도 **수집은 됩니다** — 제목과 링크만 담기고
> 가격·상품번호는 비는 것뿐입니다. 어느 쪽인지 답이 알려 줍니다.

### 쓰는 법

타오바오 앱 → 상품 → **공유 → 링크 복사** → 단축어 실행.
또는 공유 시트에서 바로 단축어를 고르셔도 됩니다.

### 돌아오는 답

```json
{ "ok": true, "partial": true, "item_id": "…", "title": "…",
  "price": "199", "currency": "CNY", "item_id_taobao": "993154784090",
  "uncollected": ["images", "options", "description"],
  "message": "제목·상품번호·가격까지 담았어요(공유 시점 가격). 이미지·옵션은 PC에서 고가수집기로 보강해 주세요." }
```

전체(Global) 모드였다면 `price`가 비고 `uncollected`에 `price`가 함께 들어옵니다.

## 확장이 쓰는 것

| | |
|---|---|
| `GET /api/v1/collect/enrich/pending` | 보강 대기 목록(`item_id` · `url` · `title` · `uncollected`) |
| `POST /api/v1/collect/enrich` | 추출 결과 병합(fill-only — 기존 값은 안 건드림) |

가격·통화는 **기존이 비었을 때만** 채웁니다.
