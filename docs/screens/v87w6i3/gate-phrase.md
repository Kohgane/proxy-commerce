# v87-W6 item 3 (확장) — 팝업 문구 3분: 미실행/비상품/상품

## 오너 실기기 확정 사실 (재조사 금지·실증)
콘텐츠 스크립트 **미실행** 상태에서 팝업이 "상품 페이지가 아니에요"(판정 결과)를 표시 → 미실행과 비상품을
오도(SUPERONE 건 오판). 요구: 미실행은 "새로고침 필요"만, 판정 결과 문구는 판정이 실제로 돈 경우에만.

## 근원 (1줄)
`kgpGetPageType`가 `chrome.runtime.lastError`(콘텐츠 스크립트 부재)를 `unknown`으로 뭉개고,
`kgpSingleGateMessage("unknown")`이 "상품 페이지가 아니에요"(비상품 판정)를 반환 → **미실행=비상품 오도**.
(진단 패널은 이미 미실행을 '새로고침 필요'로 옳게 표기했으나, **수집 게이트 문구만** 뭉갬 → 불일치.)

## 수리 (확장 popup.js만 — 서버 무관)
- `kgpGetPageType`: `lastError` → **`not-injected`**, 탭없음 → `no-tab`, 실행+미결 → `unknown`, 실행+판정 →
  `single`|`list`. (미실행을 unknown으로 뭉개지 않도록 lastError 분기를 먼저.)
- `kgpSingleGateMessage`: `single`→통과 / `list`→목록 문구 / **`not-injected`·`no-tab`→'페이지 새로고침 필요'만** /
  `unknown`·기타 → 비상품 판정 문구. = **3분(미실행/비상품/상품)** + 목록.

## 문구 3분 실증 (node로 실 함수 실행)
| pageType | 문구 |
|---|---|
| `single` | (없음 — 통과) |
| `not-injected` / `no-tab` | "이 페이지에서 수집기가 아직 실행되지 않았어요. 페이지를 새로고침한 뒤 다시 시도해 주세요." |
| `unknown`(판정 돎) | "상품 페이지가 아니에요. 상품/목록 페이지에서 수집할 수 있어요" |
| `list` | "목록 페이지예요. 타일의 [수집] 버튼이나 벌크바를 쓰세요" |

→ 미실행 문구 ≠ 비상품 문구(오도 제거). 미실행엔 "상품 페이지가 아니" 문구 미포함.
