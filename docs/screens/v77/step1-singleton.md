# v77 STEP1 — 주입 경로 단일화 (버튼 단일 시스템 · 옵션 B: 다중 선택 유지)

## 배경(오너 캡처 확정 증상)
아마존 검색결과 타일별 제각각: 호버 없이 상시 버튼 / 좌상+중앙 이중 버튼 / 버튼 전무. 구·신 버튼 주입 경로 병존.

## 근본 원인 (2겹)
1. **이중 상시 노출**: 좌상 코너 선택배지(`.kgp-card-chk`, "수집" 라벨·**상시**) + 이미지 중앙 호버 알약(`.kgp-card-quick`)이
   둘 다 노출 → '좌상+중앙 이중 버튼'.
2. **opacity 무력화**: 호버 알약의 hover-hide용 `opacity:0`이 **비-!important**인데, v72 STEP4 격리
   `all:initial !important`가 `opacity`를 initial(1)로 **!important** 덮어써 무력화 → '호버 없이 상시 버튼'.

## 수리 — 단일 버튼 시스템 (옵션 B, 오너 확정)
- **상시 노출 봉인(핵심)**: `.kgp-card-quick`(호버 [수집])·`.kgp-card-chk`(선택 토글) **둘 다** opacity를 `!important`로 +
  호버 토글을 `setProperty("opacity", …, "important")`로 → all:initial 격리를 이겨 **호버 시에만 노출**. '상시 버튼' 근절.
- **선택 토글 = 호버 전용**: 좌상 배지를 삭제하지 않고 **호버 전용**으로 전환(미선택·비호버=숨김, **선택되면 유지**) →
  **다중 선택(선택 수집)·다시 수집 존속**(오너 요청). 라벨을 "수집"→**"선택"**으로 구분해 '이중 [수집]' 오인 방지.
- **[수집] 단일화·멱등**: 타일당 `.kgp-card-quick` 최대 1개(`:scope .kgp-card-quick` 자손 조회, 재스캔·가상화 갱신만),
  이중 감지 시 `console.warn` 후 잉여 제거. 타일 `data-kgp="done"` 마킹.
- **표시 정책**: 미수집=호버 시 [수집]+선택 동시 노출(터치=상시 소형) / 수집됨=상시 '수집됨 ✓' / AD=상시 미니 배지.

## 옵션 결정 이력
브리프의 "타일당 버튼 최대 1개"+"상시 [수집] 금지"가 상시 선택배지와 충돌 → 초안(옵션 A)은 다중 선택 폐기였으나,
**오너가 "B로 가라"** 확정 → 다중 선택 유지(선택 토글을 호버 전용화). '수집 버튼'은 여전히 타일당 1개(중앙 [수집]),
선택 토글은 별개 소형 컨트롤(호버 전용)로 공존.
