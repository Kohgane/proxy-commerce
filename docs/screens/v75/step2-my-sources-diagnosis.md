# v75 STEP2 — My Sources(유저 등록 소싱처) 자가진단

## 목적
유저가 등록한 소싱처가 **어디까지 수집되는지** 화면에서 확인. 등록 소싱처의 상품 페이지 1곳에서 테스트 추출 →
[제목·가격·이미지·옵션·상세] **필드별 ○/×** 를 카드에 저장·표시. 3핵심(제목·가격·이미지) 미달=**수동 보완 필요**
안내(등록/수집은 **차단하지 않음**).

## 구현
- **순수 진단 `diag_from_scraped(scraped)`**(my_sources_store): 추출 결과 → 필드별 ○/× + `core3_ok`(제목·가격·이미지)
  + `missing_core`. 실제 추출 결과만(가짜 0).
- **서버 진단 `diagnose_source_fields(url)`**: 상품 예시 URL을 서버가 읽어 `UniversalScraper`로 필드 진단. 봇 차단/실패는
  `status=blocked`로 정직 표기(확장 자가진단 안내). **확장(브라우저 DOM) 자가진단 결과 직접 전달 경로**도 지원(봇차단 사이트).
- **라우트 `POST /seller/sourcing/my-sources/diagnose`** → 진단 → `save_diagnosis`(카드에 저장, 미등록이면 자동 등록).
- **UI**: My Sources 카드에 필드별 ●/○ 줄 + [진단] 버튼(상품 URL 입력) + 3핵심 미달 시 **수동 보완 필요** 배지.
- **제네릭 추출기 순서 감사**: 어댑터 없는 사이트도 **ld+json Product → og/meta → DOM 휴리스틱** 순으로 3핵심 추출
  (요시다형 제네릭 계약 픽스처 `synthetic-generic-detail`로 검증 — 어댑터 없이 제목·가격·이미지 ✓).

  (● 제목 / ○ 가격·이미지 → **수동 보완 필요**) + [진단] 버튼.

## 금지 준수
진단 없는 '지원' 표기 0(실 추출 결과만) · 3핵심 미달로 등록/수집 차단 0(안내만) · 가짜 성공 0(봇차단=정직 blocked).
