# v75 STEP1 — 디폴트 마켓 커버리지 매트릭스 (전수·정직)

## 목적
전 디폴트 마켓(13개)의 9항목(목록·호버·상세·제목·가격+통화·갤러리·옵션·상세·리뷰) 지원 수준을 명문화.
**근거는 실페이지 하네스 픽스처의 실제 어서션뿐**(추측 기입 금지). 픽스처 없으면 '미검증' + 오너 스냅샷 요청.

## 구현
- **매트릭스 `docs/coverage_matrix.md`**: `src/collectors/sourcing_registry.py`의 `coverage` 데이터 단일 소스에서
  `scripts/gen_coverage_matrix.py`로 **파생**(수기 편집 금지). 버튼 3열=제네릭 감지로 전 사이트 보장(v70/v74),
  추출 6열=하네스 검증분만 ✓, 그 외 '픽스처 필요'.
- **콘솔 배지**: 소싱처 가이드(`/seller/guide/sources`)에 마켓별 **추출 지원** 배지 —
  **완전 지원**(제목·가격·갤러리·옵션·상세 검증)·**부분 지원**(누락 필드 명시)·**미검증**(스냅샷 필요) +
  **스냅샷 필요 마켓 섹션**(오너가 각 사이트 상세 1곳에서 '진단 스냅샷 저장').
- **정직 게이트**: 가드가 level=full/partial로 claim한 필드가 **실제 expected.json에 어서션돼 있는지 강제** →
  '진단 없는 지원' 표기 원천 차단.
