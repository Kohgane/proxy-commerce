마켓 연결

내 마켓 API 키를 직접 입력하고, 저장 전에 연결을 테스트할 수 있어요.

발급 가이드 ← 마켓 현황으로
여기에 넣는 건 ‘내 마켓 키’(쿠팡·네이버 등에서 발급받은 본인 API 키)예요. 서버 환경변수(MARKET_CRED_ENC_KEY 같은 인프라 키)와는 다릅니다 — 그건 운영자가 관리하고, 여기엔 입력하지 않아도 됩니다.
입력한 키는 안전하게 암호화되어 보관돼요. ?
한 마켓씩 순서대로 연결하기
연결을 마치면 로 자동 체크돼요. 천천히 하나씩 하면 됩니다.

쿠팡

미연결
연결 3단계 — ① 키 발급받기 · ② 아래에 붙여넣기 · ③ 연결 테스트. 모두 이 화면에서 진행돼요.
① 키 발급받기
쿠팡 윙(Wing) 열기
↑ 이 버튼만 마켓 사이트가 새 탭으로 열려요(로그인 필요). 키를 받은 뒤 이 화면으로 돌아오세요.
② 받은 키 붙여넣기
📦 출고지·반품지 정보 — 상품 등록에 필수 (한 번만 입력하면 모든 등록에 자동 사용) 배송프로필
이 항목은 쿠팡에만 필요해요. (다른 마켓엔 없어요.)
쿠팡 윙에 로그인할 때 쓰는 아이디(이메일/ID). Vendor ID(A+숫자)와 다릅니다.
쿠팡 윙 → 판매자정보 → 배송정보(출고지/반품지) → ‘출고지’의 코드(숫자). 예: 7437895
쿠팡 윙 → 배송정보 → ‘반품지’의 센터코드(숫자). 예: 1000274592
반품지 주소의 우편번호 5자리. 예: 06236
반품을 받을 기본주소. 예: 서울특별시 강남구 테헤란로 123
동·호수 등 상세주소. 예: 4층 101호
반품을 받는 담당자명 또는 상호. 예: 코가네CS
반품 문의 전화번호. 예: 02-123-4567
편도 반품배송비(원). 비워두면 5000원으로 자동 설정됩니다.
③ 저장하고 연결 테스트
