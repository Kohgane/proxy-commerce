# v81 STEP1 — 북마클릿 간이 폴백 정직화 (되다안되다 종결)

## 증상(오너 실기기 1.5.114~118)
북마클릿 수집이 "됐다 안 됐다" — 어떤 땐 풀 수집, 어떤 땐 제목·이미지만(간이). 사용자는 왜 그런지 모름.

## 근본 원인
run.js 로더 타임아웃이 **2.5s**로 짧아 느린 네트워크에서 run.js(확장 추출기)가 못 실려 **침묵**하며 코어(간이)
폴백. 어느 경로였는지 표시가 없어 '됐다 안 됐다'로 체감.

## 수리
1. **타임아웃 2.5s→6s** — run.js 로드 여유(주된 flakiness 원인 제거).
2. **localStorage 캐시**(`kgp_runjs`): 성공 로드 시 run.js 텍스트 캐시 → **다음 클릭 즉시**(네트워크 대기 0)
   캐시 eval로 `__kgpRun` 사용 + **백그라운드 갱신**(cacheRun, best-effort·CSP 차단 시 무시).
3. **코어 폴백 정직화**(침묵 금지): 폴백 발동 시 토스트 `"간이 수집(제목·이미지만) — 네트워크 지연으로 확장
   수집기 미로드"` + `data.mode='core'` 전송 → 서버 `extra.mode='core'` 저장.
4. **이력 '간이' 배지**: 수집이력에서 `mode=='core'`면 **⚡ 간이** 배지(warn 토큰·이모지 0), 클릭 → 드로어
   `[다시 수집]`으로 상세·가격 보완 유도. 확장 풀수집은 mode 미전송 → `'full'`(배지 없음).
5. 코어 버전 스탬프 `bm-v72b`→**`bm-v81`**(토스트·설치 안내 동기).
