# v67 STEP2 — 보강 렌더 보장 (테무 1/5의 근원)

## 근원
- 백그라운드 탭은 브라우저가 렌더/타이머를 스로틀 → `document.hidden=true`, lazy 이미지·가격 노드 미출현 → 테무 보강이 "핵심 정보 못 읽음 1/5"로 실패.

## 수리
### 1) 렌더 보장 = 별도 소형 창 (기본)
- 보강 탭을 `chrome.windows.create({type:"popup", width:480, height:640, top:90, left:90, focused:false})`로 순차 오픈 — 탭이 **활성**이라 렌더 보장, 우측 소형이라 화면 점유 최소.
- 설정(`kgp_enrich_mode`): **`window`(기본)** / `tab-activate`(탭 순간 활성화) / `background`(기존). 팝업 `상세 보강 방식` 셀렉트.

### 2) 렌더 대기 강화 (`extractMetaWait`)
- **자동 스크롤**(상→하, 최대 4초)로 lazy 이미지·가격 트리거 후 원위치.
- **인터스티셜 감지·닫기**(`_kgpDismissInterstitial`): 앱 유도·지역 게이트·큰 모달(뷰포트 40%↑ 고정 오버레이) → 닫기 버튼 클릭, 닫아도 남으면 `interstitial=true`.
- **가격+갤러리 대기 최대 12초**(`kgpWaitRendered(…, 12000)`).
- **타임아웃 원인 로그**: `priceOk / imgOk / hidden / interstitial` — 어느 조건 미충족인지 서버가 아닌 F12 콘솔에.

### 3) 테무 성공 기준 + 정직 실패 (`_kgpEnrichVerdict`)
- 테무: **가격 실가 + 갤러리 자기 상품 ≥3장**. 미달이면 `throw`(보강 완료 처리 안 함 → 재시도/‘보강 실패’ 정직).
- 인터스티셜이면 **"테무 로그인/게이트로 보강 불가"** 정직 표기.
- 비테무는 엄격 게이트 없음(관용).
