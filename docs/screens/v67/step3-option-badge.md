# v67 STEP3 — 옵션 미수집 문구 검증

## 증상
- 옵션이 비면 무조건 "옵션 미수집"(경고색) — 무옵션 상품(단일 상품, 정상)과 추출 실패를 구분 못 함.

## 수리 (`collect_preview.html` 드로어 옵션 탭)
- 옵션 0개일 때 **핵심 필드 판독 여부**(`coreOk = 이미지 있음 && 가격 있음(needs_check 아님)`)로 분기:
  - `coreOk` → **무옵션(단일 상품)**: `단일 상품` **중립 배지**(한지/muted 토큰, 경고색 아님) + "옵션 없는 단일 상품이에요".
  - `!coreOk` → **추출 실패**: `옵션 미수집` **경고 배지**(주황 warn) + "상품 정보를 완전히 읽지 못해… 보강 후 다시 확인".
- 두 경우 모두 `+ 옵션 추가`로 직접 입력 유도(막다른 길 없음).

## 판정
- 가드 `tests/test_v67_option_badge.py` (4): coreOk 분기·무옵션 중립 토큰·추출실패 경고색·needs_check 게이트·양 경로 수동추가·렌더 200.
- 실기기(무옵션·유옵션 상품 각 1건 배지 구분 캡처)는 오너 환경 — 프록시 라이브 차단.

## 금지 준수
- 가짜 성공 0(needs_check 가격은 판독으로 안 침)·토큰 외 색 0(한지/muted·warn 토큰).
