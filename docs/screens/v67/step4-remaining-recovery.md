## 정직 — 라이브 미회수 (오너 검증 몫)
개발 환경은 프록시가 라이브 아마존/테무를 차단하므로 아래 캡처를 대신 낼 수 없다(가짜 캡처 날조 금지). **이번 배치에서 미첨부 = 해당 항목 불합격**, 오너 실기기 회수 필요.

오너 회수 절차(확장 **1.5.75** 재로딩 후):
1. **아마존 보강 4필드**: 벌크 2건 → 보강 창(v67 STEP2) 완주 → 드로어 [갤러리 고해상·상세 불릿·옵션·리뷰] 채움 + 상태 배지 성공. 실패 시 `[enrich]`·F12 `[고가수집기 보강]` 로그로 원인 특정.
2. **번역 3건**: 유효 OPENAI/DEEPL 키 설정 → 아마존 영문 3건 벌크 번역 → 자연 한국어 상품명 + 실패 0. 실패 시 `[collect 번역]`·응답 `fail_reason`.
3. **북마클릿 2필드**: 북마클릿으로 아마존 1건 → 옵션·상세 채움.
