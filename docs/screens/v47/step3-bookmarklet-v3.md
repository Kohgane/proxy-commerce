# v47 STEP3 — 북마클릿 v3 (진단 → 코드 복사·URL칸 붙여넣기)

## 진단 (v46 파일 가져오기가 실기기서 여전히 실패한 이유)
1. **이스케이프**: 정상. `_netscape_bookmark`가 `html.escape(quote=True)` → HREF에 원시 `"`/`&`/`<>` 0(가드 test_netscape_file_valid_and_escaped).
2. **URL 길이**: v46서 29KB→2.9KB로 이미 해결(추출기 인라인 폐기, 서버 추출).
3. **남은 근본 = 방법 자체의 취약성**:
   - 최신 크롬은 **북마크 HTML 가져오기 시 `javascript:` HREF를 보안상 드롭**하거나, 가져온 항목이 **‘가져온 항목/Imported’ 폴더에 묻혀** 사용자가 못 찾는 경우가 있다.
   - **주소창에 `javascript:` 를 붙여넣으면 크롬이 접두어를 제거**한다(anti-XSS) → 주소창 경로도 막힘.
   - 즉 '가져왔는데 클릭 무반응' / '가져오기 자체 실패'가 크롬 버전·정책에 따라 갈린다 — 파일 가져오기는 통제 불가.

## 결론 & 전환
**유일하게 크롬 정책에 안 걸리는 경로 = 북마크 편집 대화상자의 URL 칸에 붙여넣기.**
(가져오기-드롭도, 주소창-스트립도 안 거침. 편집창 URL 칸은 `javascript:` 를 그대로 받는다.)

- **주 방법(신규)**: `① 북마클릿 코드 복사` 버튼 → `POST /seller/bookmarklet/code`(토큰 발급 후 `javascript:` 코드 텍스트 반환) → 클립보드 복사 → 안내 3단계:
  1. 아무 페이지 **Ctrl+D**(⌘+D) → 북마크 추가 → **수정/편집**
  2. 편집창 **URL 칸**에 **붙여넣기**(주소창 아님)
  3. 이름 **고가수집기** → 저장.
- **대체 방법(강등)**: 파일 받기 → chrome://bookmarks 가져오기 → 가져온 항목 드래그(아이콘 자동). 크롬이 막으면 코드 복사로 유도.
- **정직**: 토큰 저장 실패면 코드/파일 둘 다 안 준다(503, 가짜 성공 0).

## 검증
- `/seller/bookmarklet/code`: 200 `{ok, code}`, `code` 는 `javascript:` 시작 + 내 토큰 baked + `/api/v1/collect/extension`. 토큰실패=503, 미인증=401.
- 페이지: '북마클릿 코드 복사' 주 버튼 + URL칸/주소창 경고 + 파일 대체 details. test_client 200 실측.
- 가드 test_v47_bookmarklet_code(5) + test_v39b 갱신(주=코드복사·대체=파일). 전체 회귀 그린.

## 최종 판정(오너 실기기)
오너가 kohganepercentiii.com/seller/bookmarklet 에서 **코드 복사 → 북마크 편집창 URL칸 붙여넣기 → 상품 페이지 클릭 → 수집 완료**를 확인(실기기 캡처). 이 경로는 크롬 가져오기/주소창 스트립을 우회하므로 실패 지점이 제거된다.
