# v47 STEP5 — 엑셀 벌크 내보내기 / 업로드

## 위치
수집이력(`/seller/collect/history`) 벌크바: **엑셀 내보내기** / **엑셀 업로드** / **템플릿**.

## 내보내기
- 선택 상품(체크) → 그 항목만, 선택 없으면 전체(최신 5000) → `.xlsx`.
- 열: 상품ID·제목(한)·제목(영)·카테고리·가격(KRW)·옵션(JSON)·썸네일URL·갤러리URL(`|`구분)·상세이미지URL(`|`)·키워드(`,`)·상태·수집일·원본URL.
- 이미지는 **URL 텍스트**(임베드 아님). openpyxl.
- 템플릿: 헤더 + 예시 1행(`GET /collect/export-template`).

## 업로드 (확인 후 적용 — 즉시 적용 아님)
1. 파일 선택 → `POST /collect/import-xlsx`(**검증만**) → 리포트 모달: **신규 N / 갱신 M / 오류 K**(행#·사유) + 미리보기.
   - 이 단계에서 데이터는 **안 바뀐다**(테스트로 못박음).
2. ‘적용’ → 같은 파일 재전송 `POST /collect/import-apply` → 실제 적용.
   - **상품ID 있으면 갱신, 없으면 신규.** 내 목록에 없는 ID = 오류(남/삭제 항목 갱신 금지).
   - **오류는 행별**(그 행만 건너뜀, 전체 롤백 아님). 결과: 신규 X · 갱신 Y · 오류 Z.
   - 신규는 append(트랜잭션 커밋 durable 확인), 갱신은 기존 extra 병합 후 update. collect_status(STEP2) 재판정.

## 안전/한도
- 5000행 상한, 초과 시 리포트에 안내(잘림 표시).
- 가격 비숫자·옵션 JSON 오류·빈 행 = 행별 오류 사유 표기(가짜 성공 0).
- 파일 20MB 상한. 미인증 401.
