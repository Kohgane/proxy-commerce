# v65 STEP2 — 제외 43 감사

## 원칙
- **"제외 (광고 등)" 뭉뚱그림 금지.** 제외 사유별 카운트 분해를 확장 디버그 패널에.

## 수리 (`content_script.js` / `popup.js`)
- `_kgpExcl = { ad, region, parse, url, dup }` — 스캔마다 `_kgpExclReset()`로 초기화.
  - **ad**: 광고(스폰서) — 태깅만·전체선택 제외(제외 아님, 카운트).
  - **region**: 비상품영역(추천/푸터/캐러셀).
  - **parse**: 카드 파싱 실패(유효 ASIN 없음·제목/이미지 둘 다 없음·가격·상세링크 둘 다 없음).
  - **url**: URL 추출 실패(앵커 없음).
  - **dup**: 중복(같은 상품 href / 중첩 ASIN).
- 아마존·제네릭 어댑터의 각 제외 지점에서 해당 카운터 증가.
- `kgpDetectState` 응답에 `excl` 포함 → 팝업 `감지 진단` 패널이 **`제외: 광고 N · 파싱실패 N · URL실패 N · 중복 N · 비상품영역 N`** 표기.

## 파싱 실패 상위 원인 (지속 완화 — v63~65 누적)
- generic-first 병합(어댑터 실패가 제네릭 미차단, v63) + 앵커 폴백(테무 SPA, v63) + 스폰서 오제외 박멸(v64) → 실상품 인식율 향상. 이번 STEP은 **어느 사유로 몇 개 빠지는지**를 실측 노출(다음 수리의 근거).
