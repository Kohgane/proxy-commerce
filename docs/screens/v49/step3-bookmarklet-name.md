# v49 STEP3 — 북마클릿 이름 버그 수리 (U+200B → '고가수집')

## 근원 (오너 실기기 확정)
파일 방식 북마클릿(NETSCAPE HTML)의 `<A>` 앵커 텍스트가 **제로폭 공백 U+200B**였다(v40-B가
'아이콘만 표시'를 노려 넣음). 그런데 크롬 가져오기 후 북마크 **이름이 투명/빈칸**으로 보여 사용자가
북마크바·폴더에서 **못 찾는** 버그의 근원. (아이콘도 크롬 버전에 따라 안 붙으면 완전 안 보임.)

## 수리
- `_netscape_bookmark(..., label="고가수집")` — 기본 앵커 텍스트를 **가시 문자열 '고가수집'**으로.
  이름이 또렷이 보이고, 빈 문자열의 `javascript:` URL 폴백 우려도 해소. `html.escape`로 안전.
- **생성 파일 파싱 검증 테스트**: 다운로드 파일의 `<A>` 앵커 텍스트를 정규식으로 추출 → 제로폭/공백뿐이
  아닌 가시 문자('고가수집')인지 단언(투명 이름 재발 방지).

## 병행 (복사 방식 1순위 — v47서 도입, v49 안내 정교화)
- `POST /seller/bookmarklet/code`(토큰 발급 후 javascript: 코드 반환) → **[코드 복사]** 버튼.
- 3단계: ① 코드 복사 → ② **Ctrl+Shift+O**(북마크 관리자) → ③ 빈 곳 우클릭 → **새 북마크 추가** →
  **URL 란에 붙여넣기** → 이름 **고가수집** → 저장.
- **주소창(맨 위)에는 붙여넣지 말 것** 굵게 경고(크롬이 `javascript:` 접두어 제거).
- 파일 방식은 접이식(대체) — '가져온 항목' 폴더에서 북마크바로 꺼내는 안내 유지.

## 판정 (오너 실기기)
(a) 파일 가져오기 → **폴더에서 이름 '고가수집'이 보임** → 북마크바로 이동 → 클릭 수집 성공.
(b) 코드 복사 방식(Ctrl+Shift+O → 새 북마크 → URL 붙여넣기) 설치 → 클릭 수집 성공.
각 캡처. (앵커 텍스트 가시성은 생성 파일 파싱으로 로컬 실증 — 가드 test_v49_bookmarklet_name.)

## 가드
test_v49_bookmarklet_name(3): 생성 파일 앵커 가시 문자 + 기본 라벨 가시 + 복사 안내/주소창 경고.
test_bm_import_file 갱신(제로폭 폐기 → '고가수집' 가시).
