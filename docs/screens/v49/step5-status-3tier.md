# v49 STEP5 — 수집 상태 3단계 (성공/부분/실패—원인)

v47 STEP2가 성공/부분 + 토스트 + 드로어 수집 로그를 이미 냈다. v49 잔존분 = **'실패—원인' 3번째 단계**.

## 3단계 판정 (단일 소스 collect_status.py)
- **성공**: 7개 필드 전부 present → 목록 `성공 N/7`(초록).
- **부분**: 일부 누락(핵심 중 일부는 있음) → `부분 · {누락 필드명}`(주황).
- **실패**: 핵심 3(제목·가격·이미지)이 **전부** 미확보(저장은 됐으나 추출 실패) → `실패 · 추출 실패`(빨강)
  + 원인 `추출 실패 — 핵심 정보(제목·가격·이미지)를 못 읽었어요`.
  (전송 실패=502·인증 실패=401·CSP는 레코드가 안 생기므로 토스트/HTTP가 사유 — v47서 처리.)

## 3곳 반영
- **목록 상태 컬럼**(collect_history_rows.html): 성공/부분/**실패** 배지. 옛 레코드도 렌더 시 재판정.
- **드로어 수집 로그**(collect_preview.html): 헤더에 성공/부분/**실패 — 원인** + 필드별 present·소스.
- **토스트**(content_script.js): 성공 `수집 완료(N/7)` / 부분 `부분 수집 — X 누락` / **실패 `수집 실패 — {원인}` +
  '직접 입력하거나 다시 시도'**. 실패는 축하 없음.
