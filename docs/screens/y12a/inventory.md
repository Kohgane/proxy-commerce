# Y12-A 화면 정리 — 지금 보이는 글자 전부 (승인용)

캡처: `docs/screens/y12a/before-*.png` · 글자 원본: `before-*.txt` (`scripts/_devshot_y12a.py before`로 다시 뜸).

쿠팡 API 값 → 화면: `승인대기중`·`심사중`·조회 막힘(400 DEFAULT) → 승인대기 / `승인완료`·`부분승인완료` → 승인완료 / `승인반려` → 승인반려 / `임시저장` → 임시저장(Wing 표기).

## 결정 필요

1. **모바일 뱃지 글자.** 390px 한 줄에 「썸네일 + 상품명 + 『고가네 승인완료』×4 + 시각」은 안 들어간다. 제안: 모바일은 **마켓 약자 + 색**(「고」「우」「셰」「코」 — 초록 승인완료·판매중 / 회색 승인대기·판매대기 / 빨강 승인반려), 단 **승인반려·실패는 약자 대신 「반려」·「실패」 글자**. 상태 낱말 전체는 데스크톱 줄·드로어·팝업 제목에. 데스크톱은 「고가네 승인완료」 그대로.
2. **온보딩 「5분 시작 가이드」 줄** 삭제 — 예전 「지우지 않는다(활성화 퍼널)」 규칙과 충돌. 삭제하고 메뉴로만 둘지.
3. **「오늘 쓴 것」 상한** — 코드 기본 200(env `IMAGE_TRANSLATE_DAILY_CAP`). 화면 분모는 env 값 그대로 쓴다(400이면 400).
4. **「오너 확인 대기」 범위** — 지우기 제안 사진 · 등록 보류(위험·사전검증) · 「확인 필요」 원문 줄. 이 셋으로 시작.
