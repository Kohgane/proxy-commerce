# Y12-A 화면 정리 — 지금 보이는 글자 전부 (승인용)

캡처: `docs/screens/y12a/before-*.png` · 글자 원본: `before-*.txt` (`scripts/_devshot_y12a.py before`로 다시 뜸).
재료: VRSUK 운영값(10-17 등록 기록·갱신 기록·다듬기 기록). 마켓 조회는 DB 기록 그대로(캡처 환경에서 밖으로 안 나감).

표시: **남김** · **접음**(「자세히」 안으로) · **삭제** · 남김 줄에 `→` 가 있으면 문구를 바꿔 남김.

상태 낱말(원칙 1): 쿠팡 = **승인대기 · 승인완료 · 승인반려**(Wing 표기). 네이버 = **판매중 · 판매대기**(그 밖의 네이버 상태는 판매자센터 이름 그대로: 품절·판매중지·판매종료·승인대기·승인거부·판매금지·삭제).
쿠팡 API 값 → 화면: `승인대기중`·`심사중`·조회 막힘(400 DEFAULT) → 승인대기 / `승인완료`·`부분승인완료` → 승인완료 / `승인반려` → 승인반려 / `임시저장` → 임시저장(Wing 표기).

## 금지(원칙 3) 확인 — 지금 사용자 화면에 보이는 것

- PR 번호·커밋 해시: 캡처 화면엔 없음(코드 주석에만).
- UTC: 없음(전부 KST 변환). 「HTTP 200」(팝업 조건부) → 접음.
- 호출 횟수·캐시 수: 다듬기 결과줄(AI 9회·캐시 210상자), 이미지 번역 실패 줄(텐센트 호출 n/n) → 접음.
