# v56 STEP1 — 북마클릿 로더 구조 (침묵 사망 원천 제거)

## 문제
v55 북마클릿(추출 로직 내장 5KB)이 실기기에서 **토스트 포함 완전 무동작 — 초기 구간 침묵 사망**. 구버전(경량)은 작동.

## 2계층 구조
- **인라인 코어(≈3KB, 검증된 구버전 로직)**: `K()` 토스트 **최우선 정의** → **즉시 '수집 중…' 표시** → og메타 +
  기본 이미지(naturalWidth≥300) + outerHTML 수집 → 전송. **이 코어만으로 구버전 수준 수집 보장.**
- **로더**: 코어가 `S+'/seller/bookmarklet/run.js?v='+Date.now()`를 script로 주입 시도. 로드 성공 → 확장판
  (`window.__kgpRun`: 갤러리 스코프·srcset 최고해상·판매가 PR·h1)이 코어 데이터를 대체. 실패(CSP)·2.5초 타임아웃 →
  코어가 그대로 진행. **어느 경로든 토스트·수집 반드시 발생.**
- **토큰 T는 코어 closure에만** — run.js URL·본문에 노출 0(run.js는 추출 로직만, 전송은 코어가 T로).
- 이득: 이후 추출 개선은 **run.js 재배포만으로 반영**(북마클릿 재설치 불요).

## 안전
- 전 구간 `try{…}catch` + **최후 보루 alert 1회**(토스트 생성조차 실패 시). 토스트 K()도 내부 catch에서 alert 폴백.
  **침묵 금지.**
- 파일: **앵커 텍스트 빈 문자열**(오너 요청 — 파비콘만 표시), ICON v181 favicon-32, PERSONAL_TOOLBAR_FOLDER 유지.
  안내에 "아이콘만 보이는 게 정상" 명시. (제로폭 U+200B는 여전히 금지 — 완전 빈 "".)

## 자가 테스트
- `/seller/bookmarklet` "설치 테스트 열기" → 자체 호스팅 데모 상품(`/seller/bookmarklet/testpage`, ld+json+갤러리)
  새 탭 → 거기서 북마클릿 클릭 → **토스트(#kgpbm) 감시 → 초록 판정**("북마클릿 작동 확인"). 오너가 3초 판별.

## 로컬 실증
- 코어 3078자(<6000, 가져오기 안전). run.js valid·토큰 미노출·`__kgpRun` 정의. 코어: K 정의→'수집 중…'→로더 순서.
  run.js·testpage·bookmarklet 페이지 200. 앵커 빈문자열·ICON.

## 판정 (오너)
테스트페이지 초록 판정 + 일반 쇼핑몰 토스트('수집 중…'→완료) 복원 + CSP 강성 사이트 코어 폴백 수집 캡처.
