# 모바일 수집 — iOS 단축어 · 텔레그램 (M1-4)

폰에서 소싱하다 괜찮은 상품을 만났을 때, **공유 한 번으로 수집·검수까지** 끝내는 방법입니다.
PC 크롬 확장이 못 도는 자리(아이폰·외출 중)를 메웁니다.

셋 중 편한 걸 쓰시면 됩니다.

| 방법 | 설정 | 쓸 때 |
|---|---|---|
| **iOS 단축어** | 5분(한 번) | 사파리·쇼핑앱 → 공유 → 고가브릿지 수집 |
| **텔레그램** | 오너가 서버 env 설정 | 봇 대화창에 URL 붙여넣기 |
| PWA 공유 | 앱을 홈 화면에 추가 | 안드로이드 공유 → 고가브릿지 |

---

## 1. 준비 — 토큰 발급 (단축어용, 1회)

1. 콘솔 → **내 토큰**(`/seller/me/tokens`) → 새 토큰 발급
2. 스코프 **`collect.write`** 선택
3. 발급된 값은 **그때 한 번만** 보입니다 — 아이폰 메모나 암호 앱에 바로 저장

> 토큰은 비밀번호와 같습니다. 채팅·스크린샷에 남기지 마세요. 유출됐다 싶으면 같은 화면에서 삭제(폐기)하면 그 즉시 무효가 됩니다.

---

## 2. iOS 단축어 만들기 — 5분, 액션 5개

iCloud 공유 링크는 애플 계정 없이 만들 수 없어, **직접 조립하시는 편이 빠릅니다.**
아래는 iOS 단축어 앱의 **한국어 액션 이름 그대로**입니다 — 검색창에 그대로 치시면 나옵니다.

**단축어 앱 → 우상단 `+` → 우상단 ⓘ → 「공유 시트에 표시」 켜기**

### 액션 1 — 「공유 시트에서 입력 받기」

자동으로 맨 위에 생깁니다(「공유 시트에 표시」를 켜면). 입력 종류는 **URL과 텍스트 둘 다** 켜 두세요
— 타오바오는 글 한 덩어리로 오고, 다른 앱은 URL만 주기도 합니다.

### 액션 2 — 「입력에서 URL 가져오기」

검색: `URL 가져오기`. 글 덩어리에서 링크만 뽑아 줍니다.

### 액션 3 — 「URL 확장」

검색: `URL 확장`. 단축 링크(`e.tb.cn/...`)를 펴서 최종 주소를 돌려줍니다.
그 주소에 **상품번호와 가격**이 실려 옵니다(페이지를 열지도, 로그인하지도 않습니다).

> **VPN 앱이 「규칙 모드」면 켜 둔 채로 그대로 됩니다.**
> **전체(Global) 모드면 이 액션이 막혀 제목만 담깁니다** — 그때는 단축어를 실행할 때만
> VPN을 잠깐 끄시면 됩니다(아스트릴 iOS에는 규칙 모드가 없어 끄는 쪽이 유일한 방법입니다).
>
> 전체 모드라도 **수집은 됩니다**: 제목과 링크만 담기고 가격·상품번호가 비는 것뿐이고,
> 답이 어느 쪽인지 알려 줍니다.

### 액션 4 — 「URL의 콘텐츠 가져오기」

검색: `콘텐츠 가져오기`. **여기가 본체입니다.** 아래 5칸만 채우시면 됩니다.

| 칸 | 넣을 것 |
|---|---|
| URL | `https://<우리 도메인>/api/v1/collect/one` |
| 방법 | `POST` |
| 헤더 | 키 `Authorization` · 값 `Bearer ` + **1번에서 발급받은 토큰** |
| 본문 요청 | `JSON` |
| JSON 필드 1 | 키 `share_text` · 값 = **「공유 시트 입력」**(액션 1의 결과) |
| JSON 필드 2 | 키 `final_url` · 값 = **「URL 확장」**(액션 3의 결과) |

> **값 칸을 탭하면 위에 파란 변수 칩이 뜹니다** — 거기서 해당 액션 이름을 고르시면 됩니다.
> 직접 타이핑하는 게 아니라 **칩을 고르는 것**입니다.
>
> 토큰은 `Bearer ` 뒤에 붙입니다(`Bearer` 와 토큰 사이 **공백 한 칸**).

### 액션 5 — 「결과 보기」

검색: `결과 보기`. 값에 **「URL의 콘텐츠」**를 넣으면 답이 그대로 뜹니다.
좀 더 깔끔하게 보시려면 액션 4와 5 사이에 「사전 값 가져오기」를 넣고 키에 `message`를 적으세요.

### 쓰는 법

타오바오 앱 → 상품 → **공유 → (만든 단축어 이름)**. 잠시 후 결과가 뜹니다.

## 3. 돌아오는 답 읽는 법

성공하면 이렇게 옵니다.

```json
{ "ok": true, "item_id": "…", "title": "PopSockets 그립톡", "message": "수집됐습니다." }
```

`review=1`을 켰다면 판정이 함께 붙습니다.

```json
{ "ok": true, "item_id": "…",
  "review": { "ok": true, "verdict": "검수 통과",
              "sale_krw": 19900, "margin_pct": 27.4, "ship_status": "배송가능" } }
```

**이미 수집한 상품**이면 새로 쌓지 않고 알려줍니다 — 트래킹 파라미터만 다른 주소도 같은 상품으로 잡습니다.

```json
{ "ok": true, "duplicate": true, "message": "이미 수집한 상품입니다." }
```

### 실패는 사유가 함께 옵니다

수집이 막히면 **가짜 성공을 주지 않습니다.** 무엇이 왜 안 됐는지 그대로 옵니다.

| 상황 | 응답 | 어떻게 |
|---|---|---|
| 토큰이 틀림·만료 | `401` "인증이 필요합니다" | 토큰 재발급 후 단축어 헤더 교체 |
| URL이 아님 | `400` "상품 URL이 필요합니다" | 상품 **상세** 페이지에서 공유 |
| 사이트가 봇 차단 | `502` + 사유 원문 | PC에서 크롬 확장으로 수집 |

판정만 실패했을 때는 **수집은 살아 있습니다** — `ok: true` 인데 `review.ok: false` 로 옵니다.

## 4. 텔레그램 (오너 전용)

봇 대화창에 상품 URL을 붙여넣으면 수집합니다. `검수`를 같이 쓰면 판매가·마진까지 답합니다.

```
https://www.amazon.com/dp/B0XXXX 검수
→ 수집됨 — PopSockets 그립톡
  검수 통과 · 판매가 19,900원 · 실마진 27.4% · 배송 배송가능
```

### 서버 설정 (오너 1회)

| 환경변수 | 값 |
|---|---|
| `TELEGRAM_COLLECT_WEBHOOK_SECRET` | 아무 긴 난수 문자열 |
| `TELEGRAM_COLLECT_CHAT_IDS` | 허용할 chat_id(쉼표로 여러 개) |
| `TELEGRAM_COLLECT_SELLER_ID` | 수집을 저장할 계정 식별자 |

그다음 봇 웹훅을 걸어 둡니다(텔레그램 `setWebhook`, 주소는 `/webhooks/telegram/collect`,
시크릿 토큰은 위 `TELEGRAM_COLLECT_WEBHOOK_SECRET` 과 같은 값).

> **셋 중 하나라도 비어 있으면 수집하지 않고 거절합니다.** 잠금 장치가 없는 상태를 '열림'으로
> 해석하지 않기 때문입니다. 특히 허용목록이 비어 있으면 **아무도** 쓸 수 없습니다 —
> 시크릿만으로는 주소를 아는 누구나 우리 수집 이력에 쓸 수 있어서입니다.

## 5. 안 될 때

| 증상 | 원인 | 조치 |
|---|---|---|
| 단축어가 401만 반환 | 헤더가 `Bearer ` 접두 없이 들어감 | `Bearer` + 공백 + 토큰 |
| 텔레그램이 무반응 | 허용목록에 내 chat_id가 없음 | `TELEGRAM_COLLECT_CHAT_IDS` 확인 |
| 텔레그램이 503 | 시크릿·스코프 env 누락 | 위 표 3개 다 채웠는지 확인 |
| 목록 페이지를 공유함 | 상세가 아니라 검색·목록 주소 | 상품 **상세** 페이지에서 공유 |

## 관련

- 수집한 상품 확인: 콘솔 → **수집 이력**
- 검수표·마켓 등록: 콘솔 → **소싱 URL 검수**(`/seller/sourcing/register-pipe`)
- PC 대량 수집: 크롬 확장(`/seller/extension`)
