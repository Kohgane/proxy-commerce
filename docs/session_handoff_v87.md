## §1. 채점 규칙 (누적분 — 위반 시 보고 미완 처리)
1. **스냅샷 채점 금지 · 실브라우저 증빙 필수.** 추출/갤러리/수집 판정은 `fixtures/realpages/*` 스냅샷 + Playwright(L2 계보) 계약으로. jsdom 간이는 보조.
2. **'없음 확인' ≠ '수집 실패'.** 단일 상품(옵션 없음)·리뷰 0 확인은 만점 분모에서 제외(4/4). 수집 실패는 정직 표기(원인 명시).
3. **정직 데이터 절대.** 가짜 성공·임의 환산·Mock·가짜 수치 0. 미연결/실패는 빈 상태+안내.
4. **매 트랙 완료 4항** = 계약 그린 + before/after 캡처(실행 결과만) + 회귀 0(전 스위트) + PR 셀프점검 체크리스트. "했다" 문장만으로 닫지 말 것.
5. **장부 고정 섹션 강제.** 보고 첫 블록은 트랙 상태 표(해시/진행/미착수), 항목 누락 시 보고 전체 미완.
6. **자율 머지** = 셀프 게이트(CI 5체크 그린 + 계약 + 캡처) 충족 시 즉시(draft 대기 금지). 머지 후 브랜치를 origin/main으로 동기화(force).
7. **전체 스위트 실행 중 브랜치 전환 금지**(실행 중 소스 바뀌면 결과 무효·exit 0 착시). 워크트리 분리하거나 완주 후 전환.

2. **draft 교착 (3회).** PR을 draft로 두고 "머지해도 되냐" 승인 대기해 진행이 3번 멈췄다. **셀프 게이트(CI 5체크+계약+캡처) 충족 = 자율 즉시 머지**(§1-6). draft 대기 금지 — 오너가 이미 자율 머지를 지시했다.
3. **장부 실종 규율.** W2-impl(주문 상태 색 A안)이 보고에서 **3회 실종**(회수 목록에만 있고 상태 미표기). → **보고 첫 블록 = 트랙 상태 표 강제**(§1-5). 완료분도 표에 해시로 명시, "회수 대기"로 뭉개지 말 것.
