# 고가수집기 — 크롬 확장

지정한 **소싱처**(타오바오·티몰·1688·테무·아마존·알리익스프레스 등)에서 한 클릭으로 상품을 고가브릿지에 수집합니다.

> **v1.5.0 — 지정 소싱처에서만 노출**: 수집 버튼/바는 **내가 지정한 소싱처에서만** 뜹니다(그 외 사이트엔 아무것도 안 보임).
> 확장 아이콘 → **소싱처 관리**에서 기본 소싱처를 켜고/끄거나 **도메인을 직접 추가/삭제**할 수 있어요.
> 또한 **실제 제품 카드만** 감지합니다(상단 추천·‘본 적 있음’ 썸네일·푸터 제외) → ‘N개 발견’ = 실제 수집 가능 수.

## 🚀 설치 방법 (개발자 모드 — 당나귀도 할 수 있어)

**준비물**: 크롬 브라우저 + GitHub에서 다운받은 리포 ZIP

1. `chrome://extensions/` 주소창에 입력 → 엔터
2. 우측 상단 **개발자 모드** 토글 → 파란색으로 켜기
3. **압축해제된 확장 프로그램 로드** 버튼 클릭
4. 폴더 선택 창에서 `extensions/chrome-collector/` 폴더 선택 (이 폴더 자체를!)
5. "고가수집기" 카드가 나타나면 ✅ 설치 완료

> **주의**: 폴더 안의 파일이 아니라 `chrome-collector/` **폴더 자체**를 선택해야 함.

## 🔑 토큰 발급 방법

확장이 서버에 연결하려면 Personal Access Token이 필요합니다.

1. `https://kohganepercentiii.com/auth/login` 접속 → 로그인
2. 사이드바 **🔐 API 토큰** 클릭 (또는 직접 `/seller/me/tokens` 접속)
3. **＋ 새 토큰 발급** 클릭
4. 스코프: `collect.write` 체크 (크롬 확장 필수)
5. 만료: 기본 1년 권장
6. **발급하기** 클릭 → `kgp_...` 로 시작하는 64자 토큰이 표시됨
7. **지금 바로 복사** — 이 화면을 벗어나면 영영 다시 볼 수 없음!
8. 1Password, 노트 등 안전한 곳에 붙여넣기

## 📦 사용 방법

### 방법 1: 아이콘 클릭
1. 쇼핑몰 상품 페이지 접속
2. 주소창 오른쪽 **🛒 고가수집기 아이콘** 클릭
3. **이 상품 수집하기** 버튼 클릭
4. 팝업에 ✅ 표시 + 텔레그램 알림 도착 = 성공

### 방법 2: 우클릭 메뉴
1. 상품 페이지에서 마우스 **우클릭**
2. **고가브릿지에 보내기** 선택
3. 수집 완료 알림 확인

### 방법 3: 인페이지 '수집' 버튼 (v1.1+)
1. 상품 페이지에 접속하면 **우하단에 고가수집기 글로브 아이콘 + “고가수집기 수집” 버튼**이 자동으로 떠 있음
   (상품 페이지로 인식될 때만 표시 — og:product / 가격 메타 / JSON-LD Product 기준)
2. 버튼 클릭 → 그 자리에서 수집 + **자동 한국어 번역**(서버에서 수행)
3. 페이지 안에 ✅/❌ 토스트로 결과 표시. 셀러 콘솔에서 확인·편집하면 됨

### 방법 4: 검색·목록 페이지에서 여러 상품 한 번에 수집 (v1.4+)
1. 쇼핑몰 **검색결과/카테고리/목록 페이지**(상품이 여러 개 나열된 화면)에 접속
2. 상품 카드마다 **‘수집’ 배지**가 좌상단에 뜸 → 클릭하면 ‘✓ 선택’(개별 취사선택)
3. 화면 상단 **고가수집기 수집 바**에서 `전체 선택` / `선택 수집` / `전체 수집`
4. 선택한 상품들이 **한 번에** 수집돼 셀러 콘솔 **수집 이력**에 쌓임(번역 포함)

> 목록 페이지 수집은 카드에 보이는 정보(제목·이미지·가격·링크)를 모읍니다.
> 상세설명·옵션·리뷰까지 필요하면 그 상품의 상세 페이지에서 ‘고가수집기 수집’을 누르세요.

#### 더 편하게 쓰기 (v1.4.8+)
- **수집 바 접기/펼치기**: 바의 `✕`로 접으면 화면 구석에 작은 **‘수집 열기’ 배지**(선택 개수·은은한 펄스)만 남아요. 배지를 누르면 다시 펼쳐집니다(선택은 유지).
- **자동/수동(📌)**: 바의 `📌 자동`을 누르면 `수동`으로 바뀌어, 이후 목록 페이지에서는 자동으로 펼치지 않고 **구석 배지로만** 시작합니다(원할 때만 펼침).
- **드래그로 위치 이동**: 단일 상품 **수집 버튼**과 **수집 바/배지**를 마우스로 끌어 원하는 곳에 두면 **위치를 기억**합니다.
- **수집 도장**: 실제 수집에 성공하면 누적 건수 카운트업과 마일스톤(10·50·100…) 배지가 잠깐 표시됩니다(접근성 설정 ‘동작 줄이기’를 켜면 생략).

> 번역은 서버에 `OPENAI_API_KEY`(또는 `DEEPL_API_KEY`)가 있을 때 작동합니다.
> 키가 없으면 원문 그대로 저장되고, 셀러 콘솔 편집 페이지에서 수정할 수 있습니다.

## 🛠 트러블슈팅

### ❌ "확장 프로그램을 로드하지 못함. icons/16.png 없음"
> 구버전 `chrome-collector/` 폴더를 사용 중입니다.
> **해결**: GitHub에서 최신 리포 ZIP을 다시 다운로드 → `chrome-collector/` 폴더에 `icons/` 디렉터리가 있는지 확인 → 확장 삭제 후 재설치.

### ❌ "토큰이 설정되지 않았습니다"
> 확장 옵션 페이지에서 Personal Access Token을 입력하지 않았습니다.
> **해결**: [토큰 발급 방법](#-토큰-발급-방법) 참고 → 옵션 페이지에서 토큰 입력 → 저장.

### ❌ "인증 오류 (401)" / "토큰이 유효하지 않습니다"
> 토큰이 만료되었거나 회수된 것입니다.
> **해결**: `/seller/me/tokens`에서 새 토큰 발급 → 옵션 페이지 업데이트.

### ❌ 수집 버튼 눌렀는데 반응 없음
> 1. 서버 URL 확인 (`https://kohganepercentiii.com`, 끝에 `/` 없어야 함)
> 2. 서버 상태 확인: `https://kohganepercentiii.com/health`
> 3. 크롬 확장 콘솔 확인: `chrome://extensions/` → 오류 클릭

### ❌ CORS 오류
> 확장의 content_script가 브라우저 컨텍스트에서 직접 메타를 추출하므로 일반적으로 CORS가 발생하지 않습니다.
> 서버 API(`/api/v1/collect/extension`)는 기본적으로 CORS 허용 설정 포함.

## 🔄 확장을 새 버전으로 갱신하려면

**권한이 변경되지 않은 경우:**
1. `chrome://extensions/` 접속
2. "고가수집기" 카드의 새로고침(↻) 버튼 클릭

**권한이 변경된 경우 (예: scripting 권한 추가):**
1. 카드의 "삭제" 버튼 클릭
2. 본 레포 ZIP을 다시 다운로드 (또는 `git pull`)
3. `chrome://extensions/` → "압축해제된 확장 프로그램 로드" → 새 폴더 선택

> ⚠️ **"executeScript 관련 에러"** 가 보이면 권한이 갱신되지 않은 상태입니다.
> 반드시 삭제 후 재로드하세요.
