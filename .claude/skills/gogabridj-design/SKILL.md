# 고가브릿지 디자인 시스템

## 정체성 (브리프가 못 박은 방향 — 그대로 따른다)
"디지털 한지 위의 금속활자" = 네오클래식 에디토리얼 + Apple식 스크롤 내러티브.
- 모델: 노재고 구매대행 SaaS, 1인 셀러 대상. 양방향 게이트(수입형 KRW / 수출형 USD).
- 주의: "크림 배경 + 세리프 + 테라코타"는 AI가 흔히 내놓는 default다. 우리 정체성과 겹치지만 **이건 브리프가 지정한 방향이라 따른다.** 다만 게으른 default로 끝내지 말고, 아래 **시그니처(다리)**로 차별화한다.

## 시그니처 (이 페이지만의 기억점 — 반드시 살린다)
**다리/게이트/키스톤이 시그니처다.** 장식이 아니라 구조로 쓴다:
- 섹션을 잇는 곳에 다리 모티프(아치·데크 라인)를 은은하게.
- "수집→번역→편집→등록→주문"을 **다리를 건너는 흐름**으로 시각화(번호 카드는 실제 순서가 있을 때만).
- 키스톤(주황 점)은 화면당 1개의 시선 고정점으로만.
- 보랏빛·과한 그라데이션·두꺼운 보더·이모지·지구본 금지(절대원칙).

## 토큰 (app.css 단일 소스 — 하드코딩 hex/px 금지)
```
--ink:#1A1714      /* 먹 — 텍스트·외곽·CTA */
--hanji:#F5EFE3    /* 한지 — 보조 배경 */
--paper:#FBF8F1    /* 종이 — 메인 배경 */
--gold:#C9A24B     /* 금 — 포인트·다리 */
--teal:#119A8E     /* 청록 — 링크·브랜드 */
--teal-bright:#0FC2C0
--orange:#F5821F   /* 주황 — 주요 CTA·키스톤만 */
--line:#E6DECB  --muted:#8A8275  --ink-soft:#3A352E
--r:18px  --shadow:0 1px 2px rgba(26,23,20,.06),0 8px 30px rgba(26,23,20,.08)
```
**강조 1색/화면 원칙:** CTA만 주황, 링크·상태는 청록, 포인트는 금. 한 화면에 강조색 1개.

## 타이포 (역할별 2종 이상 — 의도적 페어링)
- 헤드라인: **Noto Serif KR**(700/900) — 클래식·금속활자. 자간 -.02~-.035em, 큼직하게.
- 본문: **Pretendard**(+Inter) — 현대·가독.
- 데이터/캡션: Pretendard 작은 굵기.
- H1는 `clamp(40px,6.4vw,76px)`. 타이포 자체가 기억점이 되게.

## 레이아웃
- **랜딩:** 글래스 슬림 내비(blur, 60px, 알약 CTA) → 대형 세리프 히어로 + "1분 만에 시작" eyebrow → 풀블리드 콘솔 샷(브라우저 크롬바 포함) → 3-피처 → 5단계 파이프라인 → 좌카피/우비주얼 split → 후기 슬롯(정직: 가짜 후기 금지, "베타 모집") → 먹색 CTA 밴드 → 푸터. 섹션 패딩 96px.
- **콘솔:** 좌 사이드내비(활성=먹 배경+청록 아이콘), KPI 3카드, 리스트 행(썸네일+상태뱃지). 글자·버튼·이미지 충분히 크게(작게 만들지 말 것).
- 반응형: 860px 이하 사이드내비 숨김, 카드 1열, split 세로. 터치 타깃 ≥44px.

## 컴포넌트 규칙
- **버튼:** primary(먹 또는 주황)·ghost(흰+라인), 알약형, hover translateY(-2px)+그림자. 죽은 버튼 0.
- **상태 뱃지:** 번역완료=청록, 가격 확인 필요=주황, 실패=적. 전 화면 공통 컴포넌트.
- **카드:** 흰 배경+--line 보더+--shadow, radius --r. hover 살짝 떠오름.
- **드로어:** 우측 슬라이드 오버레이(새 창·라우트 이동 금지). 모바일은 풀스크린 바텀시트.

## 카피 (디자인 재료다)
- 톤: "건방지지만 공손한 높임말" 큐레이터. 픽투셀식 친근함은 참고하되 문구 복제 금지.
- 사용자 언어로: "알림 관리"지 "webhook 설정"이 아니다. 시스템 용어·메타 JSON·관리자 링크를 일반 유저에게 노출 금지.
- 액티브 보이스, 문장 케이스. 버튼 라벨과 결과 토스트 일치("등록" → "등록됨").
- 빈 상태·오류는 분위기 잡지 말고 **방향 제시**("무엇이 잘못됐고 어떻게 고치는지"). 가짜 성공·가짜 수치 금지(정직 데이터).

## 자기검증 (Chanel 규칙)
빌드 후 스크린샷으로 자기비평. 과한 장식 하나는 덜어낸다. 모바일·키보드 포커스·reduced-motion 보장. 화면이 default처럼 보이면 시그니처(다리)를 더 살린다.

## 레퍼런스 추출 (impeccable extract)
벤치마크 사이트 디자인을 우리 것에 녹일 때 impeccable의 `extract`를 쓴다:
- 애플(apple.com): 대형 히어로 타이포·풀블리드 제품샷·여백·스크롤 내러티브.
- 퍼센티(percenty.co.kr): 좌마켓리스트+우상세 2단, 연동상태 뱃지, 원클릭 설정 드로어, 배송프로필 카드.
- 픽투셀·윈들리·셀러픽: "1분 시작", 5단계 흐름, 친근한 단계별 톤.
- 클로드(claude.ai): 따뜻한 종이톤·세리프×산세리프 듀오·절제.
추출은 패턴만. 색·폰트·카피는 우리 토큰·톤으로 재작성(복제 금지). 퍼센티의 빽빽함은 버리고 한지 여백으로.
