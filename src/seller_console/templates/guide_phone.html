쓰는 법 — 타오바오 앱 상품 화면 → 공유 → 「고가브릿지로 수집」 → Safari가 열리며 결과가 떠요. 처음 한 번은 Safari에서 고가브릿지 로그인이 필요해요(로그인하면 같은 상품으로 돌아와요).

다른 사람에게 주기 — 단축어를 길게 눌러 공유 → 「iCloud 링크 복사」 → 링크를 받은 사람은 한 번 탭으로 추가해요.

안드로이드 — 앱으로 설치

  1. 크롬에서 고가브릿지를 열고 메뉴 ⋮ → 「앱 설치」(또는 「홈 화면에 추가」)
  2. 타오바오·테무·알리 앱 상품 화면 → 공유 → 「고가브릿지」
  3. 결과 화면에서 담긴 제목·가격을 확인

공유 목록에 「고가브릿지」가 안 보이면 앱 설치가 끝나지 않은 거예요 — 1단계를 다시 해 주세요.
