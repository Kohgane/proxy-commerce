고가수집기 설치하기

설치하면 쇼핑몰에서 버튼 한 번으로 상품이 담겨요. 한 단계씩 따라오면 1~2분이면 끝나요.

고가수집기가 뭐예요?
쇼핑몰 상품 페이지에서 제목·가격·이미지를 한 번에 가져오는 도우미예요. 하나하나 복사할 필요 없이 버튼 한 번이면 끝나요.
토큰은 왜 넣어요?
토큰은 “이 수집기가 내 계정 것”임을 알려주는 열쇠예요. 딱 한 번만 넣으면, 가져온 상품이 내 계정으로 쏙 들어와요.
잘 안 되나요? (자세한 도움말)
버튼이 안 보이면: ① 확장이 켜져 있는지 ② 확장 관리 화면에서 새로고침(↻) ③ 지정 소싱처의 상품/목록 페이지인지 ④ 확장 옵션에 토큰이 들어갔는지 확인하세요. 모바일은 크롬 확장을 지원하지 않아요 — 상품 주소를 복사해 수집기에 붙여넣거나, 앱을 홈 화면에 추가한 뒤 쇼핑 앱에서 공유 → 코고가네로 보내면 됩니다.
