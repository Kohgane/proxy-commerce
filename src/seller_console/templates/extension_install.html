최신 확장 버전 {{ version or '1.5.147' }} · 최신 확장 내려받기 — 받은 뒤 chrome://extensions에서 새로고침(↻)하면 최신으로 갱신돼요.
고가수집기가 뭐예요?
쇼핑몰 상품 페이지에서 제목·가격·이미지를 한 번에 가져오는 도우미예요. 하나하나 복사할 필요 없이 버튼 한 번이면 끝나요.
토큰은 왜 넣어요?
토큰은 “이 수집기가 내 계정 것”임을 알려주는 열쇠예요. 딱 한 번만 넣으면, 가져온 상품이 내 계정으로 쏙 들어와요.
잘 안 되나요? (자세한 도움말)
버튼이 안 보이면: ① 확장이 켜져 있는지 ② 확장 관리 화면에서 새로고침(↻) ③ 지정 소싱처의 상품/목록 페이지인지 ④ 확장 옵션에 토큰이 들어갔는지 확인하세요. 모바일은 크롬 확장을 지원하지 않아요 — 아래 폰에서 수집하기를 보세요.
{# M1-4 — 폰에서 수집. 개발 표기(환경변수·문서 경로) 없이 셀러가 따라 할 수 있는 만큼만. #}
폰에서 수집하기 (아이폰 · 안드로이드)

안드로이드 — 앱을 홈 화면에 추가한 뒤 쇼핑 앱에서 공유 → 고가브릿지로 보내면 바로 수집돼요.

아이폰(단축어) — 공유 시트에서 한 번에 수집합니다. 5분이면 끝나요.

  1. 내 토큰에서 상품 수집 권한으로 토큰을 발급하세요 (발급 값은 그때 한 번만 보입니다).
  2. 단축어 앱 → 새 단축어 → 공유 시트에서 받기를 켭니다(입력: URL).
  3. URL 콘텐츠 가져오기를 추가하고 이렇게 채웁니다.
    주소 {{ request.host_url.rstrip('/') }}/api/v1/collect/one
    방법 POST · 본문 JSON
    헤더 Authorization = Bearer (발급받은 토큰)
    JSON url = 단축어 입력(공유된 주소)
  4. 판매가·마진까지 보고 싶으면 JSON에 review = 1을 더하세요 (몇 초 더 걸립니다).
  5. 마지막에 결과의 message를 알림으로 보여주면 끝입니다.

수집이 막히는 사이트(봇 차단)는 실패 사유를 그대로 알려드려요 — 그때는 PC에서 확장으로 수집하시면 됩니다.
