🧩 고가네 수집 — 크롬 확장 설치

설치하면 쇼핑몰 상품/검색 페이지에 ‘고가네 수집’ 버튼이 떠서 클릭 한 번에 수집됩니다.

확장 다운로드 (v{{ version or '—' }})

설치 방법 (1~2분)

  1. 위 ‘확장 다운로드’를 눌러 kohgane-collector-v{{ version }}.zip을 받고 압축을 풉니다 → manifest.json이 들어있는 폴더가 생깁니다.
  2. 크롬 주소창에 chrome://extensions 입력 → 엔터. 📋 복사
  3. 오른쪽 위 ‘개발자 모드’를 켭니다(토글 ON).
  4. 왼쪽 위 ‘압축해제된 확장 프로그램 로드’ 클릭 → 방금 압축 푼 폴더(안에 manifest.json이 보이는 그 폴더)를 선택. ※ ‘매니페스트 없음’ 오류가 나면 한 단계 안쪽 폴더(manifest.json이 바로 보이는 폴더)를 고르세요.
  5. ‘코고가네 수집기’가 확장 목록에 나타나면 설치 완료 ✅
  6. 확장의 옵션에 개인 토큰을 넣습니다(딱 1회). 토큰 발급 →
    확장 아이콘 우클릭 → ‘옵션’ → 서버 URL {{ request.host_url.rstrip('/') }} + 토큰 붙여넣기
  7. 쇼핑몰 상품 페이지로 가면 우하단에 고가네 수집 버튼이, 검색/목록 페이지엔 카드마다 수집 배지가 뜹니다.
버튼이 안 보이면: ① 확장이 켜져 있는지(파란 토글) ② chrome://extensions에서 새로고침(↻) ③ 상품 상세 페이지인지(목록 페이지는 카드 배지) ④ 옵션에 토큰이 들어갔는지 확인하세요.

📱 모바일에서 수집하기

모바일 브라우저는 크롬 확장을 지원하지 않습니다. 대신 두 가지 방법이 있어요.

  1. URL 붙여넣기: 상품 페이지에서 주소 복사 → 고가네 수집기에 붙여넣고 즉시 수집.
  2. 공유하기(안드로이드): 고가네 퍼센티를 홈 화면에 추가(앱처럼 설치)하면, 쇼핑 앱에서 공유 → 고가네 퍼센티로 보내 바로 수집됩니다.
