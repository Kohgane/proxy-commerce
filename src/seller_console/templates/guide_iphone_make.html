단축어 만들기 (한 번)

만든 단축어의 iCloud 링크를 아래에 붙여넣으면 유저용 설치하기 화면의 파란 버튼이 그 링크로 열립니다.

{# P(오너 2026-10-01) — 운영 도착 기록: 쿼리 9자 `v=2&text=` · text 0 · clip 0. 단축어 미리보기엔 전체 URL이 있었다 → iOS 「URL 열기」가 비ASCII 앞에서 자른다(영문만은 통과). 그래서 URL에 비ASCII가 남지 않게 **두 번** 인코딩한다(P1). 그래도 잘리면 URL을 버리는 길(P2 — 아래). iOS 화면 이름은 오너 실측 라벨만 쓴다. #}
  1. 「단축어」 앱 열기 → 오른쪽 위 「+」.
  2. 위쪽 단축어 이름 옆 「∨」 → 「세부사항」 → 「공유 시트에 표시」 켬.
  3. 동작 여섯을 이 순서로 둡니다(「동작 추가」 → 검색창에 이름). 「만약」·「클립보드 가져오기」 단독 동작은 넣지 않습니다: {# Q(2026-10-01) 운영 도착 기록: 카드(复制链接 → 단축어) 길은 담겼고(쿼리 1893자), 공유 시트 길은 쿼리 9자 `v=2&text=`로 잘렸다. 링크만 따로 `u=`에 **맨 앞**으로 싣는다 — 뒤가 잘려도 링크는 산다. #}
    1. 공유 시트에서 받기 — 공유 시트를 켜면 맨 위에 생깁니다. · 받을 종류: 파란 글자를 눌러 종류 화면(제목 「단축어 입력」)에서 텍스트 · 리치 텍스트 · Safari 웹 페이지 · URL만 켭니다(오너 캡처: 「텍스트 및 4개」). · 「입력이 없는 경우」 = 「클립보드 가져오기」(复制链接 뒤 단축어 앱에서 누를 때 이 값이 들어갑니다). 오너 실측 라벨: 「훑어보기」 · 「앱 및 2개」 · 「단축어 입력」 — 자리는 C1 캡처 기준. {{ cshot("c1") }}
    2. 「입력에서 URL 가져오기」 — 입력 칸에 파란 「단축어 입력」 토큰. 공유 글에서 링크만 뽑습니다. {{ cshot("c2") }}
    3. 「URL 인코딩」 — 입력 칸에 ②의 결과 토큰(「URL」). 링크는 영문뿐이라 한 번이면 됩니다. {{ cshot("c3") }}
    4. 「URL 인코딩」 — 입력 칸에 파란 「단축어 입력」 토큰 → 결과 「URL 인코딩된 텍스트」. {{ cshot("c4") }}
    5. 「URL 인코딩」 한 번 더 — 입력 칸에 ④의 결과 토큰. 글(제목)엔 한자가 있어 두 번 인코딩합니다 — 운영 도착 기록: 한 번이면 아이폰이 `text=` 뒤를 잘랐고(10-01 10:35, 쿼리 9자), 두 번이면 다 왔습니다(13:49, 1893자 · 서버가 한 번 더 풂). {{ cshot("c5") }}
    6. 「URL 열기」 — 「URL」 칸에 아래를 그대로 입력하고, u= 뒤엔 ③의 결과, text= 뒤엔 ⑤의 결과 토큰: {{ share_base }}/seller/collect/share?v=2&u=[③ 결과]&text=[⑤ 결과] u=가 앞이어야 합니다 — 아이폰이 뒤를 잘라도 링크는 남습니다. 서버는 u로 상품을 찾고, text는 제목에만 씁니다. 「클립보드 가져오기」를 따로 동작으로 두고 그 토큰을 넣으면 빈 값이 갑니다(오너 실측). 클립보드는 ①의 「입력이 없는 경우」로 이미 들어옵니다. {{ cshot("c6") }}
    서버는 표준 디코드 뒤에도 인코딩이 남아 있으면 한 번 더(최대 2회) 풉니다 — 아래 「최근 도착」 표의 「디코드」·「링크」 칸에 나옵니다. 결과 화면 「경로」는 「단축어」로 적힙니다. v=2가 없는 옛 단축어로 들어오면 결과 화면에 「단축어가 구버전입니다」와 재설치 버튼이 뜹니다. 「입력에서 URL 가져오기」는 오너가 09-30에 쓴 동작 이름(실측)입니다.
  4. 이름을 「고가브릿지수집」으로 바꾸고 「완료」.
  5. 배포: 단축어 목록에서 이 단축어 길게 누르기 → 「공유」 → 「iCloud 링크 복사」. 이 링크를 아래 칸에 붙여넣고 저장 — 설치하기 화면의 버튼이 이 링크로 바뀝니다(유저 단축어를 따로 고칠 필요 없음).
  6. 오너 폰에서 复制链接 → 단축어 실행 1회 → 결과 화면의 「처리 단계」와 아래 「최근 도착」 표를 같이 캡처.
{# P2 — URL을 버리는 길. 두 번 인코딩해도 잘리면 이쪽. iOS 동작 이름은 오너 캡처 뒤 확정(그 전엔 「(캡처 참고)」). #}

  1. 공유 시트에서 받기 — 위 ①과 같음(입력이 없는 경우 = 「클립보드 가져오기」).
  2. 「웹에서 콘텐츠 가져오기」 (캡처 참고) — URL {{ share_in_url }} · 방식 POST · 요청 본문 「양식」 text = 파란 「단축어 입력」 토큰 (캡처 참고).
  3. 「URL 열기」 — 입력 = 앞 동작의 결과 토큰 (캡처 참고). 서버가 돌려주는 건 …/seller/collect/share?v=3&t=… 한 줄뿐입니다.
